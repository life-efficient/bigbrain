## Should trigger

- Create a new BigBrain page for Total Processing Performance after checking whether it already exists.
- Create a canonical organization page from the verified company material.
- Add a new project page when the project is distinct and the evidence supports a useful record.

## Should hand off or stop

- The requested subject already has a canonical page: hand off to `$bigbrain-update-page`.
- Two existing pages could own the subject: ask for clarification.
- The source contains only a passing mention: do not create a page.

## Should not trigger by itself

- Update an existing page with a new fact.
- Create a task with assignee and status metadata.
- Publish a page publicly.
