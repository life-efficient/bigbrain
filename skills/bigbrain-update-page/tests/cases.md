## Should trigger

- Update the NVIDIA page with a verified new strategic partnership.
- Rewrite the LPP page after a current export-control rule changes.
- Refresh a project page with a material status change while preserving its timeline.

## Should hand off or stop

- No canonical page exists: hand off to `$bigbrain-create-page`.
- Multiple pages could own the subject: ask for clarification.
- The new source adds no durable change: report a verified no-op.

## Should not trigger by itself

- Create a brand-new concept page.
- Update a task's assignee or status.
- Change a page's public visibility.
